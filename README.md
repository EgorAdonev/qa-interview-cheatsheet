# QA Cheat Sheet

Интерактивная русскоязычная шпаргалка для изучения **QA Automation / Java / Systems**.

## Что внутри

- Java Core, OOP, Collections, Streams, exceptions, generics, concurrency
- алгоритмы и структуры данных: 19 подробных учебных карточек (Big O, Java Collections, arrays, two pointers, sliding window, binary search, prefix sums, graphs, DP, DSU, Dijkstra)
- JUnit 5 и TestNG
- Selenium, Selenide, Selenoid, Allure
- Postman / HTTP / Rest-Assured
- Maven и CI/CD
- SQL
- Git и Kafka
- Linux, Windows и сети
- desktop GUI automation / integrations / troubleshooting
- ML и LLM — базовые концепции
- Java mini-practice
- поиск, режим «15 минут», самопроверка и прогресс в localStorage

Сайт полностью статический и не требует авторизации.

## Алгоритмы и структуры данных

Раздел [«Алгоритмы и структуры данных»](https://egoradonev.github.io/qa-interview-cheatsheet/#algorithms-roadmap) содержит:

- 19 подробных учебных карточек с Java-примерами, сложностью и задачами для самопроверки;
- 6-недельный маршрут и чек-лист задач с локальным сохранением отметок;
- прямые ссылки на CSES, учебные модули USACO Guide и AtCoder Problems;
- 3 дополнительные задачи в Java mini-practice;
- приоритеты тем и список сложных олимпиадных направлений, которые можно отложить.

Исходные файлы: `data-algorithms.js`, `algorithms-roadmap.js` и `algorithms.css`. Всё работает без backend и авторизации; прогресс хранится в localStorage браузера.

## Профессиональный практикум

39 подробных уроков: теория качества, Java, UI-автоматизация, API/SOAP/WSDL, SQL, Git/Linux/Docker/CI/CD, брокеры, Redis, мобильное тестирование и DevTools. Уроки содержат примеры, таблицы, задачи с решениями и ссылки на документацию. Восемь учебных схем демонстрируют границы, жизненный цикл дефекта, ожидания, API, JOIN и обработку сообщений. Анимации GSAP учитывают reduced motion.

Шесть SQL-заданий используют `assets/sql-practice.sql`. Полный 100-страничный PDF по мобильному тестированию доступен на сайте. Workflow восстанавливает исходный PDF из частей и проверяет SHA-256 перед публикацией.
