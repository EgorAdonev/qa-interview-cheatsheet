# QA Interview Cheat Sheet

Интерактивная русскоязычная шпаргалка для подготовки к собеседованию **Java Automation QA / POS / Desktop**.

## Что внутри

- Java Core, OOP, Collections, Streams, exceptions, generics, concurrency
- JUnit 5 и TestNG
- Selenium, Selenide, Selenoid, Allure
- Postman / HTTP / Rest-Assured
- Maven и CI/CD
- SQL
- Git и Kafka
- Linux, Windows и сети
- POS / кассовые стенды / desktop GUI automation / troubleshooting
- ML и LLM — базовые вопросы
- 3 Java mini-practice задачи из интервью-шаблона
- поиск, режим «15 минут», mock interview и прогресс в localStorage
