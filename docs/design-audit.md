# Проверка учебного интерфейса

Проверено в Chromium 133: desktop и мобильный viewport 390px. После исправления минимальной ширины кода и блока приоритетов горизонтального переполнения нет. На мобильном навигация сворачивается, поиск остаётся доступным.

Проверены 171 карточка, 39 новых уроков и 8 схем; ошибок JavaScript не обнаружено. Проверены поиск WSDL, скрытие ответов, граничное значение 17, LEFT JOIN с отсутствующим заказом, повторная доставка события, завершение API-анимации и доступность PDF. Reduced motion заменяет пошаговую анимацию статическим представлением.

Ручной аудит использует рекомендации Impeccable и Huashu: визуальная иерархия, плотность учебного материала, осмысленные схемы, видимый фокус, размер элементов управления и адаптивность. Это не запуск официального CLI и не сертификат соответствия WCAG. Эмуляция Chromium не заменяет проверку на физических iOS/Android-устройствах.
